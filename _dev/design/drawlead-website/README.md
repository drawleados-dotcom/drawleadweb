# Drawlead website

Static site. No framework, no runtime dependencies.

```
index.html          generated by build/build.py (do not hand-edit)
css/styles.css      design tokens, components, sections, illustration styles, responsive, reduced-motion
js/main.js          interaction layer (vanilla)
assets/logos/       Drawlead (dark + white + mark) and client logos, extracted from DL Web 1.pdf, WebP
assets/tech/        technology / tool logos, extracted from the content PDF, WebP
build/              Python source of truth for content + illustrations
```

## Editing content

All approved copy lives in `build/build.py` (top section: `PILLARS`, `CAPS`, `PROBLEMS`, `STEPS`, `WEEKS`, `DATA_CARDS`,
`IND_SEL`, `CASES`, `IND_FOCUS`). Illustrations live in `build/svglib.py` and `build/svglib2.py`.

```
cd build && python3 build.py     # rewrites ../index.html
```

Serve the folder with any static server (`python3 -m http.server`).

## Design notes

* Primary green `#32B46F`. Primary buttons use near-black text on green (white on this green is 2.6:1, below WCAG AA).
* Fonts: Inter + Montserrat via Google Fonts `<link>`. To self-host, download the woff2 files and add `@font-face` rules.
* Motion: reveals, marquees, and the scroll-linked problem to solution morph all respect `prefers-reduced-motion`.
  Illustrations only animate while on screen. The 8-week timeline autoplays with a pause control.
